# India Football Performance Analysis Dashboard (2014–2024)

Ten-year Tableau analysis of the Indian men's national football team, combining FIFA historical rankings with year-by-year squad data.

## Contents
- `India_Football_Performance_Analysis_Dashboard.twbx` — packaged Tableau workbook (data embedded, opens standalone in Tableau Desktop or Tableau Public — no external files needed)

## Worksheets
- Best Rank / Best Win% — India's strongest FIFA ranking and win-percentage years
- Rank Change Analysis — year-over-year FIFA rank movement
- Total Wins — win count trend, 2014–2024
- Win% Trend — win-percentage trend line
- U23 Debutants — youngest senior debutants each year, as a talent-pipeline signal

## Data Sources
- `FIFA_Historical_Ranking_Excel.xlsx` — full historical FIFA ranking data (Raw_Data, India_Ranking, India_Year_End, Summary)
- `India_Football_Evolution_Master_COMPLETE_2014_2024.xlsx` — squad-level yearly master data (average age, players used, points, goal difference, debutants)
